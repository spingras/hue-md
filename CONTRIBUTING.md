# Contributing to Hue MD

Thanks for helping. Bug reports, syntax ideas, editor fixes, and docs fixes are all welcome.

## Report a bug or suggest a feature

[Open an issue](https://github.com/spingras/hue-md/issues/new/choose) and pick the bug report or feature request form. For a bug, include the Hue source that shows the problem and say which editor or tool you used. You can test snippets in the [playground](https://spingras.github.io/hue-md/) first.

## Where things live

| Path | What it is |
| :--- | :--- |
| `src/` | The parser, renderer, and `hue-md` CLI |
| `spec/` | The syntax specification and conformance material |
| `packages/` | Editor and tool integrations (VS Code, Obsidian, Neovim, Emacs, Notepad++, Joplin, GitHub, remark, Claude Code) |
| `snippets/` | Editor snippets |
| `site/` | The playground page (generated, see below) |
| `test/` | Tests for the core parser and CLI |

`site/index.html` and `demo/index.html` are generated by `npm run demo`. Change `scripts/render-demo.js` instead of editing them directly.

## Send a change

1. Fork the repo and create a branch from `main`.
2. Install dependencies with `npm install` (Node.js 22 or later).
3. Make your change and add or update a test for it.
4. Run `npm test`. All tests must pass, including the CommonMark conformance tests.
5. Open a pull request and fill in the template.

Keep each pull request to one change. New syntax needs a spec update and an issue where it was discussed first, because every editor package has to support it.
