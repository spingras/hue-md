---
name: github
description: Convert a .hue.md file to GitHub Markdown next to it (notes.hue.md becomes notes.md), with boxes as GitHub alerts.
argument-hint: <file.hue.md>
disable-model-invocation: true
---

Write the GitHub Markdown version of the Hue file `$ARGUMENTS`.

1. If no file was given, look for `.hue.md` files in the current directory. If there is exactly one, use it; otherwise ask which one.
2. Run:

   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/scripts/sync.cjs" "<file>"
   ```

   It writes `<name>.md` next to `<name>.hue.md`, starting with a comment that marks it as generated. Boxes become GitHub alerts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`) red and orange spans become bold, and other colors become plain text.
3. If the script refuses because `<name>.md` already exists and was not generated by hue-md, show the user that file's first lines and ask before overwriting it. Only with their yes, run the same command with `--force`.
4. Report the path of the written file. Do not commit it unless the user asks.
