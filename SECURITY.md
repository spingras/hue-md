# Security Policy

## Supported versions

Security fixes go into the latest release. Please update to the newest version before you report a problem.

## Report a vulnerability

Do not open a public issue for a security problem. Report it privately instead:

- Use [Report a vulnerability](https://github.com/spingras/hue-md/security/advisories/new) on GitHub, or
- email **hallo@spingras.io**.

Describe the problem, the affected package or editor, and the steps or Hue source that trigger it. You will get a reply within a week. Once a fix is released, the report can be made public, with credit to you if you want it.
