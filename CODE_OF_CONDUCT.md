# Code of Conduct

Hue MD follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, insults, and personal attacks are not accepted in issues, pull requests, discussions, or any other project space.

## Reporting

If someone's behavior in a project space bothers you, email **hallo@spingras.io**. Reports are read by the maintainer and kept confidential.

The maintainer may edit or remove comments, close threads, or block accounts that break this code of conduct.
